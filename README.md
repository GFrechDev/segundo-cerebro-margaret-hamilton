# segundo-cerebro-margaret-hamilton
Este repositório tem como tema um dos grandes nomes (se não o maior deles) da Engenharia de Software: Margaret Hamilton. O objetivo principal é unir fontes confiáveis e com informações sólidas para gerar um agente de IA que possa atuar com a cabeça desta mulher.
As fontes utilizadas trabalham com diferentes línguas e diferentes abordagens, pórem sites de confiança, priorizando canais de notícia e principalmente aqueles voltados à tecnologia.
